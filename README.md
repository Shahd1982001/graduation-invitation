# دعوة تخرّج — لفافة مصوّرة على طاولة

```bash
npm install
npm run dev
```

## التسلسل
1. **المشهد الحقيقي**: صورة فوتوغرافية للفافة ورقية مسكّرة بفيونكة حرير ذهبية على خشب داكن (`public/assets/hero-scroll.jpg`) — بحركة تنفّس خفيفة (Ken Burns).
2. الضغط على الفيونكة (منطقة لمس فوقها في الصورة) → وميض ذهبي + **زوم على الفيونكة**، ثم **الورقة تنفرش**: صورة اللفافة المفتوحة (`scroll-open.jpg`) تُكشف من شريط في المنتصف وتتوسّع لتغطي الشاشة.
3. **زوم** على صفحة الاسم ثم تثبت.
4. **صفحات جنب بعض أفقيًا**: الاسم في المنتصف، صفحة الرسالة على اليسار، والتقويم بعدها. الصفحة في التركيز بحجمها الكامل وجيرانها مصغّرين ومقطوعين على الطرفين.
5. **انتقال تلقائي هادئ** كل `autoAdvanceMs` (انزلاق 1.6 ثانية) حتى آخر صفحة ثم يتوقف. يتوقف فورًا عند اللمس/السحب، وزر ❚❚ يوقف/يشغّل.

## استبدال الصور بصورك
- `public/assets/hero-scroll.jpg` — اللفافة المغلقة (الفيونكة في **منتصف** الصورة تقريبًا).
- `public/assets/scroll-open.jpg` — الورقة المفتوحة، ونصّ الدعوة يظهر فوقها.
- لو تغيّر مكان الفيونكة في الصورة، عدّلي `.bow-tap{left/top/width/height}` في `styles.css`.
- الأبعاد المفضّلة: 1000×1300 تقريبًا، عمودية، وأقل من 250KB.

## القيم في `src/config/grad.js`
الاسم، التخصص، الجامعة، السنة، نص الفرحة، الآية، التاريخ والوقت (توقيت ليبيا)، القاعة، رابط الخرائط، عدد المرافقين، ومدة الانتقال التلقائي.
> سطر التاريخ في صفحة الاسم يُقرأ تلقائيًا من `dateTime`.

## الملفات
- `src/components/ScrollInvite.jsx` — المشهد المصوّر ومراحل الافتتاح.
- `src/components/Filmstrip.jsx` — شريط الصفحات الأفقي (سحب/أسهم/عجلة/نقاط).
- `src/components/CalendarCountdown.jsx` — التقويم والعدّاد.
- `src/components/OvalFrame.jsx` — الإطار البيضاوي الذهبي (`frame.png`) حول صورة الخريجة.
- `src/components/RSVPDialog.jsx` + `src/services/rsvpService.js` — تأكيد الحضور (واجهة فقط، لا حفظ).
