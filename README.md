# دعوة تخرّج — لفافة بفيونكة (باقة متوسطة)

```
npm install
npm run dev
```

## القيم التجريبية: `src/config/grad.js`
الاسم، التخصص، الجامعة، السنة، نص الفرحة، الآية (طه 114 — راجعيها على المصحف)، التاريخ والوقت، القاعة، رابط الخرائط، الملاحظات، مدة التقدّم التلقائي.

## الصور: `public/assets` (كلها PNG شفاف مقصوص على حدود العنصر)
`frame.png` الإطار · `girl.png` الخريجة · `flower.png` · `stars.png` · `pearls.png` · `candelabra.png` · `paper.jpg` الورق العاجي.
- عند تغيير الإطار أعيدي قياس الفتحة: القيم في `.aperture` (left/top/width/height بالنسبة المئوية) وفي `.frame{aspect-ratio}` داخل `styles.css`.
- دقة الصور الحالية منخفضة (~400px). للنتيجة الأوضح على الهاتف ارفعي دقتها (Upscale) قبل الاستبدال.
- لا تستعملي قبعة pngtree الذهبية (عليها علامة مائية) — لم تُضمَّن.

## التشغيل التلقائي
يتقدّم الإطار كل `autoAdvanceMs` ثم يتوقف عند الأخير. يتوقف فورًا عند لمس الشاشة أو التمرير، وزر ❚❚ أعلى اليسار يوقف/يشغّل. يتوقف أثناء نافذة الحضور، ويُلغى مع «تقليل الحركة».

## RSVP
واجهة أمامية فقط ولا تحفظ شيئًا. للربط بـ Firestore عدّلي `src/services/rsvpService.js`.
