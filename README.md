# دعوة تخرّج — لفافة على طاولة

```bash
npm install
npm run dev
```

## التسلسل
1. **على الطاولة**: لفافة ورقية مسكّرة بفيونكة حرير ذهبية مربوطة حولها (ظل، إضاءة شمعة، ورق محبَّب).
2. الضغط على الفيونكة → **تتفكّ الفيونكة** (الطرفان يرتفعان، الشريط ينزلق، العقدة تتفتّت) ثم **تنفرش اللفافة** لتغطي الشاشة.
3. **زوم** على صفحة الاسم ثم تثبت.
4. **صفحات جنب بعض أفقيًا**: الاسم في المنتصف، صفحة الرسالة على اليسار، والتقويم بعدها. الصفحة في التركيز بحجمها الكامل وجيرانها مصغّرين ومقطوعين على الطرفين.
5. **انتقال تلقائي هادئ** كل `autoAdvanceMs` (انزلاق 1.6 ثانية) حتى آخر صفحة ثم يتوقف. يتوقف فورًا عند اللمس/السحب، وزر ❚❚ يوقف/يشغّل.

## القيم في `src/config/grad.js`
الاسم، التخصص، الجامعة، السنة، نص الفرحة، الآية، التاريخ والوقت (توقيت ليبيا)، القاعة، رابط الخرائط، عدد المرافقين، ومدة الانتقال التلقائي.
> سطر التاريخ في صفحة الاسم يُقرأ تلقائيًا من `dateTime` الآن.

## الملفات
- `src/components/ScrollInvite.jsx` — الطاولة واللفافة والفيونكة ومراحل الفتح.
- `src/components/SilkBow.jsx` — الفيونكة (SVG حِراري بلمعة حرير) وحركات فكّها في `styles.css`.
- `src/components/Filmstrip.jsx` — شريط الصفحات الأفقي (سحب/أسهم/عجلة/نقاط).
- `src/components/CalendarCountdown.jsx` — التقويم والعدّاد.
- `src/components/RSVPDialog.jsx` + `src/services/rsvpService.js` — تأكيد الحضور (واجهة فقط، لا حفظ).

## الصور: `public/assets`
`paper.jpg` الورق · `girl.png` الخريجة · `frame.png` الإطار · `flower.png` · `pearls.png` · `candelabra.png`.

- عند تغيير الإطار أعيدي قياس `.aperture` و`.frame{aspect-ratio}` في `styles.css`.
